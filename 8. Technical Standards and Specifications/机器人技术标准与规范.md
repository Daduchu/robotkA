# 机器人技术标准与规范

## 1. 国际标准
### 1.1 ISO标准
- ISO 10218：工业机器人安全标准
- ISO 13482：服务机器人安全标准
- ISO 15066：协作机器人安全标准
- ISO 8373：机器人术语标准

### 1.2 IEC标准
- IEC 60204：电气设备安全标准
- IEC 61508：功能安全标准
- IEC 62061：机械安全标准
- IEC 61000：电磁兼容标准

### 1.3 IEEE标准
- IEEE 1872：机器人与自动化术语
- IEEE 24730：机器人操作系统标准
- IEEE 1901：电力线通信标准
- IEEE 802.11：无线局域网标准

### 1.4 其他国际标准
- EN标准（欧洲标准）
- ANSI标准（美国国家标准）
- JIS标准（日本工业标准）
- GB标准（中国国家标准）
