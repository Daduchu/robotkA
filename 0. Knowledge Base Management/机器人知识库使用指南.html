📚 知识库管理

Knowledge Base Management

机器人知识库使用指南

1. 快速入门

1.1 访问知识库

访问方式：

  • 直接访问知识库URL
  • 通过收藏链接快速访问

1.2 界面概览

  • 顶部导航：返回首页、当前分类
  • 主内容区：当前页面内容
  • 底部导航：返回上一页

1.3 基本操作

  • 浏览：点击分类卡片进入子页面
  • 阅读：点击文件列表中的条目
  • 返回：使用返回链接回到上级

2. 内容浏览

2.1 分类导航

知识库包含11个主要分类：

  • 知识库管理 - 使用指南与模板
  • 基础概念与分类 - 机器人定义与分类
  • 核心技术 - 技术原理与实现
  • 应用领域 - 工业/服务/特种机器人
  • 发展历史与趋势 - 演进与未来展望
  • 法律法规与伦理 - 标准与规范
  • 公司与产品 - 行业分析
  • 教育与学习资源 - 培训与认证
  • 技术标准与规范 - ISO/IEC标准
  • 产业生态 - 产业链与集群
  • 前沿技术与研究 - 最新科技

2.2 内容类型

  • 文档：详细的文字内容
  • 表格：数据对比和参数列表
  • 链接：相关参考资料

3. 搜索功能

3.1 基本搜索

首页搜索框支持关键词过滤，可输入：

  • 机器人类型（如：人形、工业）
  • 技术名称（如：SLAM、深度学习）
  • 公司名称（如：小鹏、智元）
  • 应用场景（如：医疗、教育）

4. 内容贡献

4.1 创建内容

欢迎贡献内容！建议格式：

  • 使用 Markdown 格式编写
  • 包含清晰的标题层级
  • 添加相关的表格和列表
  • 注明信息来源和更新日期

4.2 内容规范

  • 准确性：确保信息来源可靠
  • 时效性：注明信息更新时间
  • 可读性：使用清晰的结构
  • 完整性：覆盖核心知识点

5. 快捷键参考

操作快捷键
搜索框输入关键词
返回首页点击顶部链接
返回上级点击返回链接

6. 最佳实践

6.1 浏览建议

  • 从首页分类开始浏览
  • 使用搜索快速定位
  • 关注更新日志了解最新内容

6.2 内容建设

  • 定期补充新内容
  • 更新过时信息
  • 完善现有条目
  • 添加交叉引用

7. 联系方式

如有问题或建议，欢迎通过以下方式联系：

  • GitHub Issues
  • 提交 Pull Request
💡 使用提示
  • 首次使用时，建议从首页分类开始浏览
  • 遇到问题时，可查看相关分类的帮助文档
  • 想要提高效率，可收藏常用分类页面
  • 有任何建议或反馈，欢迎联系作者
