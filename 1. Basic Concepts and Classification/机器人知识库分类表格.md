# 机器人知识库分类表格

| 主分类 | 子分类 | 描述 |

| **1. 基础概念与分类** | 1.1 机器人定义与基本概念 | 介绍机器人的定义、特征、发展历程、基本组成部分和分类标准 |
| | 1.2 机器人类型分类 | 按应用领域、结构形式、智能程度和移动方式等标准对机器人进行分类 |
| **2. 核心技术** | 2.1 感知技术 | 包括传感器技术、计算机视觉、语音识别和环境感知等 |

| **4. 发展历史与趋势** | 4.1 发展历史 | 包括早期发展、工业机器人时代、智能机器人时代和人形机器人发展等 |

| | 4.3 市场趋势 | 包括全球市场分析、区域市场分析、行业应用趋势和投资与融资等 |
| **5. 法律法规与伦理** | 5.1 法律法规 | 包括机器人相关法律法规、安全标准、认证体系和知识产权保护等 |

| | 6.2 中国公司 | 包括大型科技企业、专业机器人公司、创业公司和高校与研究机构等 |
| | 6.3 产品目录 | 包括工业机器人产品、服务机器人产品、特种机器人产品和人形机器人产品等 |
